# DaRuVal static redesign

Adaptación estática de la web corporativa de DaRuVal inspirada en la UI del DaRuVal Talent Program: negro, blanco roto, rojo `#ED1E2B`, tipografía editorial, etiquetas monoespaciadas, módulos numerados, cards compactas y copy directo.

## Páginas
- `index.html` — Home
- `about.html` — Sobre nosotros + Team
- `careers.html` — PLC con experiencia + DaRuVal Talent Program
- `contact.html` — Contacto

## Hero video
Añade `images/hero-loop.mp4` y opcionalmente `images/hero-poster.jpg`. El vídeo usa `autoplay muted loop playsinline`, por lo que visualmente funciona como un GIF pero con mejor calidad/control.
